# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1. In short: be respectful, assume good faith, no harassment, no
discrimination. Given the civic and political subject matter, hold an extra bar
for neutrality and good faith in discussions.

## Enforcement
Report unacceptable behavior privately to the maintainer via the repository's
contact channels. Reports are handled confidentially. Maintainers may remove
comments, commits, and contributions that violate this code, and may ban
repeat or severe offenders.

The full text of the Contributor Covenant v2.1 governs; this file is a summary.
